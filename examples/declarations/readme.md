# Declaration examples

Содержимое архива соответствует структуре `examples/declarations/` из инструкции по разработке.

- `minimal.yaml` — минимальная декларация.
- `standard.yaml` — факты, требования, архитектурные артефакты и категории.
- `regex-paths.yaml` — произвольные имена сущностей и regex для путей/имён файлов.
- `relations.yaml` — пример логических связей между сущностями.
